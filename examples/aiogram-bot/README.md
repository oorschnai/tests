# Простой Telegram-бот на aiogram

Бот отвечает на команду `/start` и получает сообщения через long polling. HTTP-сервер и домен ему не нужны.

## Локальный запуск

Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен. В каталоге этого примера выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN='токен от BotFather'
python3 bot.py
```

Откройте бота в Telegram и отправьте `/start`. Не добавляйте токен в репозиторий. Одновременно должен работать только один polling-экземпляр с этим токеном. Если у бота ранее был настроен webhook, его необходимо отключить перед запуском polling.

## Настройки для пробы в Apps

Создайте backend-приложение из этого репозитория и ветки `examples/aiogram-bot` после её публикации. Укажите путь к проекту `examples/aiogram-bot`, Python 3.12, фреймворк Flask, команду сборки `pip install -r requirements.txt` и команду запуска `python3 bot.py`. В переменных окружения приложения задайте `BOT_TOKEN`. Если панель позволяет, не добавляйте домен и HTTP health check.

Flask здесь выбирается как шаблон сборки Apps; сам бот Flask не использует. Доступность запуска без домена зависит от версии Apps и возможностей панели. При обычном backend-передеплое старый и новый экземпляры могут ненадолго работать одновременно, из-за чего polling может конфликтовать. Для проверки лучше остановить предыдущий экземпляр; альтернативный Compose-сценарий требует отдельной проверки в конкретной среде.
