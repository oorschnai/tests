# Веб-приложения на стандартной библиотеке

Три самостоятельных HTTP-приложения без фреймворков и сторонних зависимостей. Каждое отдаёт страницу на `/` и ответ 404 для остальных путей. Сервер слушает `0.0.0.0`; порт задаётся переменной `PORT` (по умолчанию `8080`).

Запускайте команды из соответствующего каталога:

```bash
cd python
python3 app.py
```

```bash
cd node
npm start
```

```bash
cd go
go run .
```

Откройте `http://localhost:8080/`. Для другого порта, например, запустите `PORT=3000 python3 app.py`. Одновременно запускаемым приложениям нужны разные порты.

При развёртывании выберите каталог соответствующего приложения как корень проекта и укажите команду запуска из примера выше. Python использует `http.server`, Node.js — `node:http`, Go — `net/http`.
