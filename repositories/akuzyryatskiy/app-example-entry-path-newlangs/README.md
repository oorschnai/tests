# app-example-entry-path-newlangs

Monorepo for `build_entry_path` e2e checks in apps-api.

## Folders

### Existing
- `bun-express` (language: bun, framework: express)
- `deno-hapi` (language: deno, framework: hapi)
- `ktor` (language: kotlin, framework: ktor)
- `axum` (language: rust, framework: axum)
- `actix` (language: rust, framework: actix)

### New frameworks (feat/new-frameworks)
- `tornado` (language: python, framework: tornado)
- `aiohttp` (language: python, framework: aiohttp)
- `fiber` (language: go, framework: fiber)
- `echo` (language: go, framework: echo) — Go 1.23+
- `quarkus` (language: java, framework: Quarkus)
- `micronaut` (language: java, framework: Micronaut)
- `solid` (language: node, framework: solid, frontend)
- `astro-ssr` (language: node, framework: astro, backend)
- `tanstack-start-ssr` (language: node, framework: tanstack-start, backend)
- `solid-start-ssr` (language: node, framework: solid-start, backend)
- `remix-ssr` (language: node, framework: remix, backend)
- `sveltekit-ssr` (language: node, framework: sveltekit, backend)
